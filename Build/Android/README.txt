Aether Grounds 1.1.0 — by Aljay Leodones

Install Aether-Grounds.apk on an ARM64 Android phone running Android 8.0 or newer with Vulkan or OpenGL ES 3.1 or newer. Allow installation from your chosen file manager when Android asks. The game works offline. The APK is locally signed for direct installation.

Tap the splash, then select Playing on a Phone. Steer with the left analog stick; hold Accelerate, Brake/Reverse, Drift or Boost with other fingers. Tap the item button to use a power-up. Reset car returns to the road. Android Back pauses/resumes or moves back through menus; it does not exit the game. Controls can be changed in Controls.
