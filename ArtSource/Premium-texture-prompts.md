# Downtown texture sources

Requested model: GPT Image 2.5 (`gpt_image_2_5`) through Higgsfield. Generation was rejected with “Requires basic plan or higher”; no job was submitted.

Final assets were generated with the built-in image generator. Its tool does not expose a selectable model version. Both generated outputs were inspected and copied intact into the project. Shader mapping uses world coordinates and triplanar projection, with repeating textures and anisotropic filtering.

- `Assets/Resources/Textures/DowntownAsphalt.png`
- `Assets/Resources/Textures/DowntownPlaster.png`

## Asphalt prompt

Use case: stylized-concept. Asset type: Unity racing game material texture. Generate a square seamless tile of weathered charcoal asphalt in a Philippine city. Orthographic top-down albedo scan, subtle fine aggregate, fine hairline wear and slightly smoother dark patches. Continuous road surface only, no markings, no text, no objects. Neutral flat illumination, no shadows, no perspective. Premium realistic game texture, not a road scene. Save output file.

## Plaster prompt

Use case: stylized-concept. Asset type: seamless Unity game building plaster albedo tile. Square orthographic flat scan of pale grey painted concrete plaster on tropical Philippine city buildings. Premium game material, fine irregular plaster grain, restrained old paint flakes, very subtle weathering, neutral grey hue so engine can tint ochre teal and terracotta. All four edges seamless. Entire canvas is plaster surface. No text, no doors, no windows, no brick pattern, no shadows, no directional illumination, no perspective.
